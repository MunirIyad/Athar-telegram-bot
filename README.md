# Medical Telegram Bot (Admin Panel & Subjects)

🤖 بوت تيليجرام طبي يحتوي على:
- مواد (جراحة، باطنة، ...).
- شباتر لكل مادة.
- ملخصات لكل شابتر.
- لوحة تحكم للإدارة من داخل البوت.

## لتشغيل البوت

1. أضف التوكن الخاص بك كمتغير بيئة:
   - `API_TOKEN=توكن_البوت`

2. نفذ الكود:
```bash
pip install -r requirements.txt
python bot.py
```

3. لتعديل صلاحيات الأدمن:
   - افتح ملف `bot.py`
   - غيّر `ADMIN_IDS = [123456789]` إلى `user_id` الخاص بك.
